The Pipeline

Five Python modules, orchestrated by GitHub Actions, running on the 1st of every month at 9:30 AM IST.

1
auth.py

Authenticate

Playwright launches headless Chromium, logs into Kite with your credentials and TOTP, and extracts the access token.

2
portfolio.py

Fetch Holdings

Pulls equity holdings, mutual fund (Coin) holdings, and open positions from the Kite API.

3
prices.py

Enrich Data

Each holding is enriched with live market data from Yahoo Finance — current price, P/E, sector, 52-week range.

4
analyst.py

Generate Report

Portfolio data + live research context is sent to Gemini, which returns a 10-section research-grade analysis.

5
emailer.py

Send Email

The final report is wrapped in a responsive HTML template and delivered to your inbox via Gmail SMTP.

Get Started in
5 minutes.

Clone, configure your secrets, and let GitHub Actions handle the rest.

1

Clone & Configure

git clone https://github.com/akamaurya/portfolio-monitor.git
cd portfolio-monitor
cp .env.example .env
# Add your Kite, Gemini, and Gmail credentials
2

Add GitHub Secrets

Go to Settings → Secrets → Actions and add your KITE_API_KEY, GEMINI_API_KEY, GMAIL_APP_PASSWORD, and other credentials.

3

Sit Back

The pipeline runs automatically on the 1st of every month. You can also trigger it manually from the Actions tab.
